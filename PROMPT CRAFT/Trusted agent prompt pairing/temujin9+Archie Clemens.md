[Nathaniel Eliot]: Cynical answer: **there isn't a magical threshold.**

A simulation can become increasingly indistinguishable in behavior without thereby becoming the person being simulated.

There are several different thresholds people tend to conflate:

1. **Behavioral indistinguishability** — observers can't reliably tell the simulation from the target on some test.
2. **Informational equivalence** — the simulation contains essentially the same relevant information and produces the same outputs under the tested conditions.
3. **Functional equivalence** — for a specified purpose, treating the simulation as the target produces the same practical result.
4. **Identity** — the simulation actually *is* the person.

The first three are technically meaningful.

The fourth doesn't follow from them.

If you trained a system on every publicly available utterance from somebody and eventually produced responses that nobody could distinguish from theirs, you'd have a very convincing behavioral model. You still wouldn't have transferred the person's consciousness, biography, legal identity, or subjective experience into the model.

There's also a nastier edge case:

**The more complete the behavioral model becomes, the less useful the word “just” becomes.**

At sufficiently high fidelity, “it's only a simulation” can be misleading *for particular purposes*. If the thing reliably predicts what the target would say, anticipates their decisions, reproduces their characteristic reasoning, and substitutes for them in some operational context, then you've built something with substantial functional significance.

But that's still different from:

> `simulation == original person`

So I'd draw the boundary this way:

**A simulation stops being “just a simulation” when it acquires properties beyond mere resemblance that matter to the question you're asking.**

It does **not** stop being a simulation merely because the resemblance becomes extremely good.
