# Why map out each region by color?

This is to isolate for the region each part of the genome that person used during activation of a cell, either receptor or transmitter.
 This is to also isolate away from extraneous noise by other netwworks within close proximity. This also allows for a way to better capture what
  and where each subgroup fired and wired. This also means breaking down each part and training each separately.

Additionally, this is useful for detecting and training away from inter-network misfires. But better yet, also opens the door to train on 
 multiple sets. This means training it on each subregion and the interstitial connections. But asynchronously as multiple fragmented networks.

This gives the option with Fasta data to allow for a higher degree of allowing it to catch up to our capacity for reason before it steps beyond
 technical limitations.
